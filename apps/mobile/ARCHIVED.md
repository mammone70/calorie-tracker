# Archived — Expo mobile app

This app has been superseded by **`apps/web`**, a mobile-first PWA that shares the same API and sync protocol via `@calorie-tracker/client`.

The mobile app is kept in the repository for reference only. Day-to-day development should use:

```bash
pnpm dev:web
```

To run the legacy Expo app:

```bash
pnpm dev:mobile
```

See the root [README](../../README.md) for current setup instructions.
